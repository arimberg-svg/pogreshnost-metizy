# Когда списываем недостачу по метизам

Простой калькулятор для акта расхождения.

- 1 кг и 0,976 кг подходит: не хватает 24 г, а можно до 50 г. 0,700 кг уже нет: не хватает 300 г.
- 300 штук и 265 подходит: не хватает 35, а можно до 36. 150–180 уже не погрешность.
- Сумма до 30 ₽. Списываем, только если количество тоже подошло.
