# Приёмка крепежа (гвозди, саморезы, болты): порядок действий при недостаче

При приёмке крепежа учитывайте объём расхождения. Если не хватает нескольких единиц и сумма недостачи по строке составляет до 30 рублей, разница списывается силами магазина. Если отсутствует значительное количество товара, оформляется полноценная недостача, даже если её общая стоимость не превышает 30 рублей.

- Вес: 5%.
- Штуки: 12%. Дробные штуки отбрасываются в меньшую сторону.
- Сумма недостачи в акте расхождений: до 30 ₽ по строке.
