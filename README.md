# Калькулятор погрешности по метизам

Магазин сам закрывает строку в акте расхождения, если сошлись три пропорции.

- Вес: **50 г на 1 кг** (5 из 100).
- Штуки: **12 штук на 100**. Дробь вверх не берём.
- Деньги: **30 ₽ на строку**. Потолок с количеством не растёт.
